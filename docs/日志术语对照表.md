# 日志术语对照表

本文件收录 COLMAP、VkSplat、VKGS 运行时常见英文日志的中文释义，供查阅。

---

## COLMAP

### 特征提取 (feature_extractor)

| 英文日志 | 含义 | 备注 |
|---|---|---|
| `Features extracted` | 特征提取完成 | 每张图一行 |
| `Indexing image ...` | 正在索引图片 | 输入阶段 |
| `SIFT extraction` | SIFT 特征提取 | CPU 或 GPU |
| `Features: N` | 该图提取到 N 个特征点 | 正常应在数百~数千 |
| `WARNING: No features found` | 该图未找到特征点 | 图片可能模糊或无纹理 |

### 特征匹配 (exhaustive_matcher)

| 英文日志 | 含义 | 备注 |
|---|---|---|
| `Matching image pairs` | 正在匹配图片对 | 暴力匹配两两组合 |
| `Matches: N` | 匹配到 N 对特征 | |
| `No matches` | 无匹配 | 两张图无共视区域 |

### 稀疏重建 (mapper)

| 英文日志 | 含义 | 备注 |
|---|---|---|
| `Registering image ...` | 正在配准图片 | 将图片纳入重建 |
| `Registered image X (Y/Z)` | 已配准第 X 张，进度 Y/Z | |
| `Triangulated N points` | 三角化了 N 个 3D 点 | |
| `Bundle adjustment` | 光束法平差 | 优化相机参数和点云 |
| `Reconstruction has N images, M points` | 重建结果：N 张图，M 个点 | 最终统计 |
| `WARNING: reconstruction failed` | 重建失败 | 通常是图片太少或无重叠 |

## VkSplat

| 英文日志 | 含义 | 备注 |
|---|---|---|
| `Vulkan device: XXX` | 检测到的 Vulkan 设备 | GPU 名称 |
| `Compiling shaders` | 编译着色器 | 首次运行 |
| `VRAM: N MB` | 显存占用 | 核显为共享内存 |
| `Training started` | 训练开始 | |
| `Epoch N` | 第 N 轮 | |
| `Forward pass` | 前向渲染 | 渲染高斯到图像 |
| `Backward pass` | 反向传播 | 计算梯度 |
| `Optimizer step` | 优化器更新 | Adam 等 |
| `Shaders must be compiled with USE_XXX=1` | 着色器编译宏需调整 | 见 VkSplat 文档 config.slang |
| `saved splat.ply` | 已保存高斯模型 | |

## VKGS (查看器)

| 英文日志 / 界面 | 含义 | 备注 |
|---|---|---|
| `Loading PLY` | 加载 PLY 文件 | |
| `N Gaussians loaded` | 加载了 N 个高斯 | |
| `FPS: XX` | 帧率 | |
| `VRAM: N MB` | 显存占用 | |

## 通用术语

| 英文 | 中文 |
|---|---|
| SfM (Structure from Motion) | 运动恢复结构 |
| SIFT | 尺度不变特征变换 |
| Bundle Adjustment (BA) | 光束法平差 |
| Sparse / Dense reconstruction | 稀疏 / 稠密重建 |
| Camera pose / extrinsics | 相机位姿 / 外参 |
| Intrinsics | 内参 |
| Triangulation | 三角化 |
| Keyframe | 关键帧 |
| Epipolar geometry | 对极几何 |
| 3DGS (3D Gaussian Splatting) | 三维高斯溅射 |
| SH (Spherical Harmonics) | 球谐函数 |
| Differentiable rendering | 可微渲染 |
| Rasterization | 光栅化 |
| Densification | 致密化 |
| Pruning | 剪枝 |
| Opacity | 不透明度 |
| Covariance | 协方差 |
| Novel view synthesis | 新视角合成 |
| PLY | 多边形文件格式（此处存高斯） |
| L1 loss | L1 损失（绝对值误差） |
| SSIM | 结构相似性 |
| PSNR | 峰值信噪比 |
| FPS | 帧率 |
| VRAM | 显存 |
