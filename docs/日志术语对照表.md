# 日志术语对照表

本文件收录本项目运行过程中出现的英文日志中文释义，供排查问题时查阅。
内容依据真实运行日志（`logs/YYYYMMDD.log`）与源码中的输出语句整理。

---

## 日志格式说明

GUI 会把每条输出统一加上时间戳与级别前缀：

```
[2026-10-01 11:55:13] [INFO] Reading COLMAP cameras from cameras.bin
```

| 级别 | 含义 |
|------|------|
| `[INFO]` | 正常流程信息 |
| `[WARN]` | 警告，流程可继续 |
| `[FAIL]` | 失败，当前步骤终止 |
| `[OK]` | 操作成功（主要用于查看器启动等） |

COLMAP 自身的日志保留了原始格式 `I日期 时间 进程号 源文件:行号] 消息`，
例如 `I20260930 15:20:26.003764 28524 incremental_pipeline.cc:620] Registering image #50`。

各阶段会打印分隔标题：

```
===== 步骤 1/3: COLMAP 特征提取 =====
===== 步骤 2/3: COLMAP 特征匹配 =====
===== 步骤 3/3: COLMAP 稀疏重建 =====
===== 步骤 4/5: VkSplat 训练 (Vulkan) =====
===== 步骤 5/5: 启动 VKGS 查看器 =====
```

## GUI 流程日志

### GPU / 路径检测

| 日志 | 含义 |
|---|---|
| `检测到独显: <GPU>，cap_max=N，图片缓存=gpu，分辨率=images_2` | 识别为独立显卡，采用较大高斯上限与 GPU 图像缓存 |
| `检测到核显: <GPU>，cap_max=N，图片缓存=cpu` | 识别为集成显卡，降低上限并改用 CPU 缓存 |
| `GPU 检测失败，使用默认设备: <异常>` | Vulkan 设备探测失败，回退默认参数 |
| `自动选择 COLMAP CUDA 版本。` | 检测到 NVIDIA GPU，选用 CUDA 版 COLMAP |
| `自动选择 COLMAP noCUDA 版本（兼容所有显卡）。` | 非 N 卡，选用纯 CPU 版 |
| `检测到非 NVIDIA GPU，自动切换到 COLMAP noCUDA 版本。` | 已配置 CUDA 版但硬件不支持，自动切换 |
| `[FAIL] COLMAP 路径未找到，请先运行 download_tools.bat。` | 工具未下载 |
| `跳过 COLMAP，复用已有稀疏重建: <sparse/0 路径>` | 该工作区已有重建结果，直接进训练 |
| `已将 COLMAP bin 文件移到 sparse/0/ 下。` | 整理 mapper 输出目录 |

### 断点续训相关

| 日志 | 含义 |
|---|---|
| `检测到训练恢复点，将从中断处继续训练。` | GUI 发现 checkpoint，将询问用户是否恢复 |
| `[INFO] 从 checkpoint 恢复，继续训练 step=N` | 训练脚本成功加载断点，从第 N 步继续 |
| `[WARN] checkpoint 加载失败，从头开始: <异常>` | 断点文件损坏或不兼容，自动改为从零训练 |
| `[WARN] checkpoint 保存失败: <异常>` | 训练中定期保存失败（不影响本次训练继续） |
| `STOPPED: 已安全停止训练，进度保存至 step=N，下次训练将从此处继续。` | 收到停止请求，已保存进度并干净退出 |

### 停止 / 结束

| 日志 | 含义 |
|---|---|
| `用户请求停止...` | 用户点击了停止按钮 |
| `已请求安全停止，等待训练保存进度...` | 已写入 STOP 标志，等待训练进程自行退出 |
| `训练已安全停止，进度已保存。` | 训练进程正常退出，进度完整保留 |
| `等待超时，已强制终止训练进程（进度回退到上一个恢复点）。` | 60 秒内未退出，强制结束，进度回退到最近自动保存点 |
| `已被用户停止。` | 非训练阶段（如 COLMAP）被强制结束 |
| `输出目录已重命名: <名称>` | 训练完成后按参数重命名输出目录 |
| `已清理 N 张验证图（节省空间）` | 删除训练用不到的分辨率副本 |
| `已将 PLY 复制到: <路径>` | 结果复制到工作区根目录 |
| `全部完成! 输出: <路径>` | 流水线结束 |
| `[OK] 查看器已启动。` | VKGS 已拉起 |

## COLMAP

### 特征提取 `feature_extractor`

| 日志 | 含义 |
|---|---|
| `Processed file [i/N]` | 已处理第 i / N 张图 |
| `Elapsed time: X [minutes]` | 本阶段耗时（分钟） |

### 特征匹配 `exhaustive_matcher`

| 日志 | 含义 |
|---|---|
| `=== Feature matching & geometric verification ===` | 匹配阶段开始 |
| `Bind FeatureMatcherWorker to GPU device 0` | 匹配器绑定到 0 号 GPU |
| `Creating SIFT GPU feature matcher` | 创建 GPU 版 SIFT 匹配器 |
| `Generating exhaustive image pairs...` | 生成两两图像对（暴力匹配） |
| `Processing block [i/A, j/B]` | 分块匹配进度（A×B 块中的第 i,j 块） |
| `in 0.039s` | 单块匹配耗时 |
| `Elapsed time: X [minutes]` | 本阶段耗时 |

### 稀疏重建 `mapper`

| 日志 | 含义 |
|---|---|
| `Loading database` | 读取特征数据库 |
| `Loading rigs...` | 读取相机装置配置 |
| `Registering image #50 (num_reg_frames=2)` | 正在配准 50 号图，当前已注册 2 帧 |
| `=> Image sees 3234 / 7668 points` | 该图观测到 3234 个点，其中 7668 为候选总数 |
| `Elapsed time: X [minutes]` | 本阶段耗时 |

> 配准进展慢（`num_reg_frames` 增长停滞）通常说明图像重叠不足或纹理过弱。

## VkSplat

| `[0] <GPU 名称> - VIABLE` | 0 号设备满足要求（`VIABLE` 可用；反之为不可用） |
| `subgroup=32, maxGroups=[...], maxThreads=[...], maxShared=49152` | 设备实际能力参数 |
| `Using device [0]` | 最终选定 0 号设备 |
| `Reading COLMAP cameras from cameras.bin` | 读取相机内参 |
| `Reading COLMAP images from images.bin` | 读取相机位姿 |
| `Reading COLMAP points from points3D.bin` | 读取稀疏点云 |
| `Loading image 1/128` | 加载第 1 / 128 张训练图 |
| `Scene scale: 1.506500` | 场景归一化尺度 |
| `112 train, 16 val, 79296 initial points` | 划分结果：112 张训练、16 张验证、初始 79296 个点 |

> 日志中的 `[32m`、`[0m` 等是终端颜色控制码，可忽略。

## VKGS（查看器）

VKGS 是独立窗口程序，GUI 以 `subprocess.Popen` 方式拉起且**不捕获其输出**，
因此日志中只会有 `[OK] 查看器已启动。` 一条。

查看时的帧率、显存等信息直接显示在查看器界面内，不写入日志文件。
可用鼠标左键拖拽旋转、滚轮缩放、右键平移。

| Sparse / Dense reconstruction | 稀疏 / 稠密重建 |

| Intrinsics | 内参 |
| Triangulation | 三角化 |
| Keyframe | 关键帧 |
| Epipolar geometry | 对极几何 |
| 3DGS (3D Gaussian Splatting) | 三维高斯溅射 |
| SH (Spherical Harmonics) | 球谐函数 |
| Differentiable rendering | 可微渲染 |
| Rasterization | 光栅化 |
| Densification | 致密化 |
| Pruning | 剪枝 |
| Opacity | 不透明度 |
| Covariance | 协方差 |
| Novel view synthesis | 新视角合成 |

| VRAM | 显存 |
| TDR (Timeout Detection and Recovery) | Windows 显卡超时检测与恢复 |

| splat | 高斯点（3DGS 元素的俗称） |
