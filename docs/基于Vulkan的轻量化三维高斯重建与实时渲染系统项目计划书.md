# 基于Vulkan的轻量化三维高斯重建与实时渲染系统项目计划书

## 一、项目概述

本项目旨在实现一套**轻量化、跨硬件、低部署门槛**的三维高斯泼溅重建与实时渲染系统。系统支持输入普通照片序列，自动完成SfM姿态重建、高斯泼溅训练、实时Vulkan渲染预览。

区别于传统3DGS方案重度依赖CUDA、Python、深度学习环境、部署体积庞大的问题，本项目采用**原型快速验证 \+ 后期轻量化重构**的迭代开发思路：

- 前期：使用Python快速搭建调度原型，跑通完整业务链路

- 后期：逐步替换为纯C\+\+/Vulkan架构，实现无CUDA、无Python依赖的轻量化交付版本

核心亮点：**渲染端基于Vulkan标准图形接口，跨显卡兼容，不绑定NVIDIA硬件，满足轻量化、通用部署需求**。

## 三、整体技术路线与系统架构

### 1\. 整体流水线

原始图片序列 → SfM姿态重建 → 高斯泼溅训练 → 标准PLY高斯模型 → Vulkan实时渲染预览

### 2\. 分层架构设计

本项目采用**解耦模块化设计**，各模块独立可替换，方便后期迭代优化：

- **调度UI层（原型Python / 最终C\+\+）**：负责路径管理、进程调用、日志输出、一键启动流水线

- **SfM重建层**：输入照片，输出相机内外参、稀疏点云（可在CUDA加速版/纯CPU轻量版之间无缝切换）

- **高斯训练层**：读取SfM结果，生成标准3DGS二进制PLY模型文件

- **Vulkan渲染层（核心自研模块）**：加载PLY高斯数据，完成GPU排序、瓦片光栅化、Alpha混合实时渲染

## 四、各模块技术方案

### 1\. 调度中间层（快速原型方案）

采用 Python \+ Tkinter \+ subprocess 实现：

- 自带GUI无需额外依赖，开发速度最快

- 接管全流程自动化：创建工作目录、调用外部程序、捕获日志、状态流转

- 仅做任务调度，不参与算法与渲染计算，架构完全解耦

后期迭代：整体替换为 C\+\+ \+ ImGui 轻量界面，彻底消除Python依赖。

### 2\. SfM姿态重建模块

原型阶段使用 CUDA加速COLMAP，保证重建速度与稳定性，快速跑通流程。

轻量化迭代阶段切换为：**无CUDA纯CPU版COLMAP / OpenMVG**，实现跨硬件、无显卡依赖重建。

### 3\. 高斯模型训练模块

采用 **VkSplat** Vulkan 训练器：

- 原生支持读取COLMAP标准SfM结果

- 可输出 SH3 完整标准PLY，完美兼容Vulkan渲染器

- 基于Vulkan计算，可彻底脱离CUDA环境，支持Intel/AMD/NVIDIA全平台GPU

### 4\. Vulkan实时渲染模块（核心开发内容）

基于nvpro vk\_gaussian\_splatting架构二次开发，为项目核心自研模块：

- 解析标准3DGS二进制PLY高斯点数据

- Vulkan StorageBuffer批量上传高斯参数

- ComputeShader完成每帧相机深度排序、视锥剔除

- 光栅化管线实现屏幕空间高斯椭圆投影、瓦片光栅化、透明混合

- 实现鼠标旋转、缩放、平移等3D交互预览功能

优势：纯Vulkan标准接口，**不依赖CUDA、不绑定N卡**，Intel/AMD/NVIDIA全平台兼容。
